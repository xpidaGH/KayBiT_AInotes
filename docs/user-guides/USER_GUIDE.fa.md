راهنمای کاربر AInotes
*********************

به AInotes خوش آمدید
====================
نرم‌افزار AInotes یادداشت‌های دست‌نویس، تصاویر تخته سفید، فایل‌های PDF اسکن‌شده و اسناد متنی (`.txt`, `.md`, `.mdx`) را برای دانشجویان علوم کامپیوتر به فضای مطالعه دیجیتال و ساختاریافته تبدیل می‌کند.

تشخیص دست‌خط و اسکن اسناد
-------------------------
1. **بوم قلم تعاملی**: الگوریتم‌ها را مستقیماً روی بوم بنویسید و با هوش مصنوعی به متن و کد تبدیل کنید.
2. **اسکنر تصویر و PDF**: یادداشت‌های دست‌نویس یا شکسته را با پروفایل‌های MyScript، Pen to Print، Transkribus، Document AI و Textract پردازش کنید.
3. **بارگذاری فایل (`.txt`, `.md`, `.mdx`)**: اسناد متنی را مستقیماً به یادداشت‌های خود اضافه کنید.

نشانه‌گذاری سبک و ۲۰ زبان برنامه‌نویسی
--------------------------------------
تشخیص خودکار Python، JavaScript، TypeScript، Java، C#، Kotlin، Dart، Bash، Rust، Go، C++، C، PHP، Ruby، PowerShell، SQL، R، Scala، MATLAB و COBOL/Assembly:
- زیر عنوان اصلی `***`، بخش `===` و زیربخش `---` قرار دهید.
- خطوط کد را با **۳ فاصله** تورفتگی بنویسید:

   def binary_search(arr, target):
       low, high = 0, len(arr) - 1
       while low <= high:
           mid = (low + high) // 2
           if arr[mid] == target:
               return mid
           elif arr[mid] < target:
               low = mid + 1
           else:
               high = mid - 1
       return -1

ابزارهای مطالعه هوش مصنوعی، خوانش صوتی و خروجی PDF
--------------------------------------------------
خلاصه، آزمون تعاملی و تحلیل خط‌به‌خط کد بسازید. یادداشت‌ها را در ۲۶ زبان با `window.speechSynthesis` بشنوید و خروجی PDF استاندارد با فونت‌های Noto بگیرید. برای جستجو **Ctrl+K** را بزنید.
