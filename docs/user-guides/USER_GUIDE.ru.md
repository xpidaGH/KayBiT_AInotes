Руководство пользователя AInotes
********************************

Добро пожаловать в AInotes
==========================
AInotes преобразует рукописные алгоритмы, снимки доски, отсканированные PDF и файлы (`.txt`, `.md`, `.mdx`) в структурированные учебные заметки для студентов компьютерных наук.

Распознавание рукописного текста и захват
-----------------------------------------
1. **Интерактивный холст для стилуса**: Пишите алгоритмы от руки и преобразуйте штрихи в цифровой текст и код.
2. **Сканер изображений и PDF**: Загружайте рукописные страницы с профилями MyScript, Pen to Print, Transkribus, Document AI и Textract.
3. **Загрузка файлов (`.txt`, `.md`, `.mdx`)**: Импортируйте или вставляйте текстовые документы напрямую.

Облегчённая разметка и 20 языков программирования
------------------------------------------------
Автоматическое определение Python, JavaScript, TypeScript, Java, C#, Kotlin, Dart, Bash, Rust, Go, C++, C, PHP, Ruby, PowerShell, SQL, R, Scala, MATLAB и COBOL/Assembly:
- Подчёркивайте заголовок `***`, раздел `===`, подраздел `---`.
- Делайте отступ **3 пробела** для блоков кода:

   def binary_search(arr, target):
       low, high = 0, len(arr) - 1
       while low <= high:
           mid = (low + high) // 2
           if arr[mid] == target:
               return mid
           elif arr[mid] < target:
               low = mid + 1
           else:
               high = mid - 1
       return -1

Инструменты ИИ, озвучивание (TTS) и экспорт PDF
-----------------------------------------------
Создавайте конспекты, тесты и разборы кода. Озвучивайте заметки на 26 языках через `window.speechSynthesis` и экспортируйте PDF со шрифтами Noto. Нажмите **Ctrl+K** для глобального поиска.
