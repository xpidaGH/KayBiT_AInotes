AInotes பயனர் வழிகாட்டி
************************

AInotes-க்கு வரவேற்கிறோம்
=========================
கணினி அறிவியல் மாணவர்களுக்காக கையெழுத்து வழிமுறைகள், வெண்பலகை புகைப்படங்கள், ஸ்கேன் செய்யப்பட்ட PDF மற்றும் (`.txt`, `.md`, `.mdx`) கோப்புகளை AInotes டிஜிட்டல் ஆய்வுப் பணிமனையாக மாற்றுகிறது.

கையெழுத்து அங்கீகாரம் மற்றும் ஆவணப் பதிவு
---------------------------------------
1. **ஸ்டைலஸ் கேன்வாஸ்**: கேன்வாஸில் நேரடியாக எழுதி, டிஜிட்டல் உரை மற்றும் குறியீடாக மாற்றவும்.
2. **படம் & PDF ஸ்கேனர்**: MyScript, Pen to Print, Transkribus, Document AI மற்றும் Textract சுயவிவரங்களுடன் கையெழுத்துப் பக்கங்களை ஸ்கேன் செய்யவும்.
3. **கோப்பு இறக்குமதி (`.txt`, `.md`, `.mdx`)**: கோப்புகளை நேரடியாக குறிப்புகளில் பதிவேற்றவும் அல்லது ஒட்டவும்.

எளிய மார்க்அப் & 20 நிரலாக்க மொழிகள்
-----------------------------------
Python, JavaScript, TypeScript, Java, C#, Kotlin, Dart, Bash, Rust, Go, C++, C, PHP, Ruby, PowerShell, SQL, R, Scala, MATLAB மற்றும் COBOL/Assembly தானாக கண்டறியப்படும்:
- தலைப்புக்கு `***`, பிரிவுக்கு `===`, துணைப்பிரிவுக்கு `---` அடிக்கோடிடவும்.
- குறியீட்டுத் தொகுதிக்கு வரிக்கு முன் **3 இடைவெளிகள்** சேர்க்கவும்:

   def binary_search(arr, target):
       low, high = 0, len(arr) - 1
       while low <= high:
           mid = (low + high) // 2
           if arr[mid] == target:
               return mid
           elif arr[mid] < target:

AI ஆய்வுக் கருவிகள், குரல் (TTS) & PDF ஏற்றுமதி
----------------------------------------------
சுருக்கங்கள், வினாடி வினாக்கள் மற்றும் குறியீடு விளக்கங்களை உருவாக்கவும். 26 மொழிகளில் `window.speechSynthesis` மூலம் கேட்டு Noto எழுத்துரு PDF ஆக ஏற்றுமதி செய்யவும். தேட **Ctrl+K** அழுத்தவும்.
