AInotes میں خوش آمدید
=====================
AInotes ہاتھ سے لکھے گئے الگورتھم، وائٹ بورڈ کی تصاویر، اسکین شدہ PDFs اور ٹیکسٹ فائلوں (`.txt`, `.md`, `.mdx`) کو کمپیوٹر سائنس کے طلبہ کے لیے منظم ڈیجیٹل نوٹس میں تبدیل کرتا ہے۔

ہینڈ رائٹنگ کی شناخت اور اسکیننگ
--------------------------------
1. **اسٹائلس کینوس**: کینوس پر براہ راست لکھیں اور اسٹروکس کو ڈیجیٹل ٹیکسٹ اور کوڈ میں تبدیل کریں۔
2. **تصویر اور PDF اسکینر**: MyScript، Pen to Print، Transkribus، Document AI اور Textract پروفائلز کے ساتھ ہاتھ سے لکھے نوٹس اسکین کریں۔
3. **فائل اپ لوڈ (`.txt`, `.md`, `.mdx`)**: موجودہ دستاویزات کو براہ راست نوٹس میں شامل کریں۔

لائیٹ ویٹ مارک اپ اور 20 پروگرامنگ زبانیں
-----------------------------------------
Python، JavaScript، TypeScript، Java، C#، Kotlin، Dart، Bash، Rust، Go، C++، C، PHP، Ruby، PowerShell، SQL، R، Scala، MATLAB اور COBOL/Assembly کی خودکار شناخت:
- عنوان کے نیچے `***`، سیکشن کے لیے `===` اور ذیلی سیکشن کے لیے `---` استعمال کریں۔
- کوڈ بلاک کے لیے سطر سے پہلے **3 خالی جگہیں** دیں:

   def binary_search(arr, target):
       low, high = 0, len(arr) - 1
       while low <= high:
           mid = (low + high) // 2
           if arr[mid] == target:
               return mid
           elif arr[mid] < target:
               low = mid + 1
           else:
               high = mid - 1
       return -1
