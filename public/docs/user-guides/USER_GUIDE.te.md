AInotes వినియోగదారు మార్గదర్శి
********************************

AInotes కి స్వాగతం
==================
కంప్యూటర్ సైన్స్ విద్యార్థుల కోసం చేతివ్రాత అల్గారిథమ్‌లు, వైట్‌బోర్డ్ ఫోటోలు, స్కాన్ చేసిన PDFలు మరియు (`.txt`, `.md`, `.mdx`) ఫైళ్లను AInotes నిర్మాణాత్మక డిజిటల్ స్టడీ వర్క్‌స్పేస్‌గా మారుస్తుంది.

చేతివ్రాత గుర్తింపు & డాక్యుమెంట్ క్యాప్చర్
-----------------------------------------
1. **స్టైలస్ కాన్వాస్**: కాన్వాస్‌పై నేరుగా రాసి, డిజిటల్ టెక్స్ట్ మరియు కోడ్‌గా మార్చండి.
2. **ఇమేజ్ & PDF స్కానర్**: MyScript, Pen to Print, Transkribus, Document AI మరియు Textract ప్రొఫైల్స్‌తో చేతివ్రాత చిత్రాలను స్కాన్ చేయండి.
3. **ఫైల్ అప్‌లోడ్ (`.txt`, `.md`, `.mdx`)**: డాక్యుమెంట్లను నేరుగా నోట్స్‌లోకి అప్‌లోడ్ లేదా పేస్ట్ చేయండి.

లైట్‌వెయిట్ మార్కప్ & 20 ప్రోగ్రామింగ్ భాషలు
-------------------------------------------
Python, JavaScript, TypeScript, Java, C#, Kotlin, Dart, Bash, Rust, Go, C++, C, PHP, Ruby, PowerShell, SQL, R, Scala, MATLAB మరియు COBOL/Assembly స్వయంచాలకంగా గుర్తించబడతాయి:
- శీర్షిక క్రింద `***`, విభాగానికి `===`, ఉపవిభాగానికి `---` ఇవ్వండి.
- కోడ్ బ్లాక్ కోసం లైన్ ముందు **3 ఖాళీలు** ఉంచండి:

   def binary_search(arr, target):
       low, high = 0, len(arr) - 1
       while low <= high:
           mid = (low + high) // 2
           if arr[mid] == target:
               return mid
           elif arr[mid] < target:
               low = mid + 1
           else:
               high = mid - 1
       return -1
