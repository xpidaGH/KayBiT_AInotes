AInotes ব্যবহারকারী নির্দেশিকা
*******************************

AInotes-এ স্বাগতম
=================
AInotes কম্পিউটার বিজ্ঞানের শিক্ষার্থীদের জন্য হাতে লেখা অ্যালগরিদম, হোয়াইটবোর্ড ছবি, স্ক্যান করা PDF এবং (`.txt`, `.md`, `.mdx`) ফাইলগুলোকে সুসংগঠিত ডিজিটাল স্টাডি ওয়ার্কস্পেসে রূপান্তর করে।

হস্তাক্ষর শনাক্তকরণ ও নথি সংগ্রহ
-------------------------------
1. **ইন্টারেক্টিভ স্টাইলাস ক্যানভাস**: সরাসরি ক্যানভাসে লিখুন এবং লেখাগুলোকে ডিজিটাল টেক্সট ও কোডে রূপান্তর করুন।
2. **ছবি ও PDF স্ক্যানার**: MyScript, Pen to Print, Transkribus, Document AI এবং Textract প্রোফাইল ব্যবহার করে হাতে লেখা নোট স্ক্যান করুন।
3. **নথি আমদানি (`.txt`, `.md`, `.mdx`)**: ফাইল সরাসরি নোটসে আপলোড বা পেস্ট করুন।

হালকা মার্কআপ ও ২০টি প্রোগ্রামিং ভাষা
-------------------------------------
Python, JavaScript, TypeScript, Java, C#, Kotlin, Dart, Bash, Rust, Go, C++, C, PHP, Ruby, PowerShell, SQL, R, Scala, MATLAB এবং COBOL/Assembly স্বয়ংক্রিয়ভাবে শনাক্ত হয়:
- শিরোনামের নিচে `***`, বিভাগের নিচে `===` এবং উপবিভাগের নিচে `---` দিন।
- কোড ব্লকের জন্য লাইনের আগে **৩টি স্পেস** দিন:

   def binary_search(arr, target):
       low, high = 0, len(arr) - 1
       while low <= high:
           mid = (low + high) // 2
           if arr[mid] == target:
               return mid
           elif arr[mid] < target:
               low = mid + 1
           else:
               high = mid - 1
       return -1
