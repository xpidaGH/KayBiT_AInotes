Gabay sa Gumagamit ng AInotes
*****************************

Maligayang pagdating sa AInotes
===============================
Ginagawang organisadong digital study workspace ng AInotes ang mga sulat-kamay na algorithm, larawan ng whiteboard, na-scan na PDF, at mga file na (`.txt`, `.md`, `.mdx`) para sa mga mag-aaral ng computer science.

Pagkilala ng Sulat-Kamay at Pagkuha ng Dokumento
------------------------------------------------
1. **Interactive na Stylus Canvas**: Direktang magsulat sa canvas at gawing digital text at code na may syntax highlighting.
2. **Image at PDF Scanner**: Mag-upload ng sulat-kamay o cursive na pahina gamit ang mga profile ng MyScript, Pen to Print, Transkribus, Document AI, at Textract.
3. **Pag-upload ng File (`.txt`, `.md`, `.mdx`)**: I-import o i-paste ang mga dokumento direkta sa iyong mga tala.

Magaang Markup at 20 Programming Languages
------------------------------------------
Awtomatikong kinikilala ang Python, JavaScript, TypeScript, Java, C#, Kotlin, Dart, Bash, Rust, Go, C++, C, PHP, Ruby, PowerShell, SQL, R, Scala, MATLAB, at COBOL/Assembly:
- Salungguhitan ang pamagat ng `***`, seksyon ng `===`, at subseksyon ng `---`.
- Maglagay ng **3 espasyo** sa unahan ng mga linya ng code:

   def binary_search(arr, target):
       low, high = 0, len(arr) - 1
       while low <= high:
           mid = (low + high) // 2
           if arr[mid] == target:
               return mid
           elif arr[mid] < target:
               low = mid + 1
           else:
               high = mid - 1
       return -1
