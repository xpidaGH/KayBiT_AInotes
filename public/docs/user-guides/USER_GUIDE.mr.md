AInotes वापरकर्ता मार्गदर्शिका
******************************

AInotes मध्ये आपले स्वागत आहे
=============================
AInotes संगणक शास्त्राच्या विद्यार्थ्यांसाठी हस्तलिखित अल्गोरिदम, व्हाइटबोर्ड फोटो, स्कॅन केलेले PDF आणि (`.txt`, `.md`, `.mdx`) फायलींचे सुव्यवस्थित डिजिटल अभ्यास कार्यक्षेत्रात रूपांतर करते.

हस्तलेखन ओळख आणि दस्तऐवज संकलन
-------------------------------
1. **इंटरॲक्टिव्ह स्टायलस कॅनव्हास**: कॅनव्हासवर थेट लिहा आणि स्ट्रोक्सचे डिजिटल मजकूर व कोडमध्ये रूपांतर करा.
2. **प्रतिमा आणि PDF स्कॅनर**: MyScript, Pen to Print, Transkribus, Document AI आणि Textract प्रोफाइलसह हस्तलिखित पाने स्कॅन करा.
3. **दस्तऐवज आयात (`.txt`, `.md`, `.mdx`)**: फायली थेट आपल्या नोट्समध्ये अपलोड किंवा पेस्ट करा.

सोपे मार्कअप आणि 20 प्रोग्रामिंग भाषा
------------------------------------
Python, JavaScript, TypeScript, Java, C#, Kotlin, Dart, Bash, Rust, Go, C++, C, PHP, Ruby, PowerShell, SQL, R, Scala, MATLAB आणि COBOL/Assembly आपोआप ओळखते:
- मुख्य शीर्षकाखाली `***`, विभागासाठी `===` आणि उपविभागासाठी `---` वापरा.
- कोड ब्लॉकसाठी ओळींपूर्वी **3 स्पेस** द्या:

   def binary_search(arr, target):
       low, high = 0, len(arr) - 1
       while low <= high:
           mid = (low + high) // 2
           if arr[mid] == target:
               return mid
           elif arr[mid] < target:
               low = mid + 1
           else:
               high = mid - 1
       return -1
