دليل مستخدم AInotes
********************

مرحباً بك في AInotes
====================
يحوّل تطبيق AInotes الملاحظات المكتوبة بخط اليد، وصور السبورة، وملفات PDF الممسوحة ضوئياً، والملفات النصية (`.txt`, `.md`, `.mdx`) إلى بيئة دراسة رقمية منظمة لطلاب علوم الحاسوب.

التعرف على خط اليد والتقاط المستندات
------------------------------------
1. **لوحة القلم التفاعلية**: اكتب الخوارزميات والمعادلات مباشرة على اللوحة وحوّلها بالذكاء الاصطناعي إلى نصوص وأكواد برمجية.
2. **ماسح الصور وملفات PDF**: اسحب صور الملاحظات اليدوية أو المخطوطات المتصلة باستخدام أنماط MyScript وPen to Print وTranskribus وDocument AI وTextract.
3. **استيراد المستندات (`.txt`, `.md`, `.mdx`)**: ارفع أو الصق الملفات مباشرة داخل ملاحظاتك.

الترميز الخفيف و20 لغة برمجة
----------------------------
يتعرف تلقائياً على Python وJavaScript وTypeScript وJava وC# وKotlin وDart وBash وRust وGo وC++ وC وPHP وRuby وPowerShell وSQL وR وScala وMATLAB وCOBOL/Assembly:
- ضع `***` أسفل العنوان الرئيسي، و`===` للقسم، و`---` للقسم الفرعي.
- أضف **3 مسافات** في بداية السطر لإنشاء كتلة برمجية تلقائياً:

   def binary_search(arr, target):
       low, high = 0, len(arr) - 1
       while low <= high:
           mid = (low + high) // 2
           if arr[mid] == target:
               return mid
           elif arr[mid] < target:
               low = mid + 1
           else:
               high = mid - 1
       return -1
