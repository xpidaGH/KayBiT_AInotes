AInotes में आपका स्वागत है
=========================
AInotes कंप्यूटर विज्ञान के छात्रों के लिए हस्तलिखित एल्गोरिदम, व्हाइटबोर्ड फ़ोटो, स्कैन किए गए PDF और (`.txt`, `.md`, `.mdx`) फ़ाइलों को एक व्यवस्थित डिजिटल अध्ययन कार्यक्षेत्र में बदलता है।

हस्तलेखन पहचान और दस्तावेज़ कैप्चर
----------------------------------
1. **इंटरैक्टिव स्टाइलस कैनवास**: कैनवास पर सीधे लिखें और स्ट्रोक्स को डिजिटल टेक्स्ट तथा सिंटैक्स-हाइलाइटेड कोड में बदलें।
2. **इमेज और PDF स्कैनर**: MyScript, Pen to Print, Transkribus, Document AI और Textract प्रोफाइल के साथ हस्तलिखित नोट्स स्कैन करें।
3. **दस्तावेज़ अपलोड (`.txt`, `.md`, `.mdx`)**: मौजूदा फ़ाइलों को सीधे अपने नोट्स में अपलोड या पेस्ट करें।

हल्का मार्कअप और 20 प्रोग्रामिंग भाषाएँ
--------------------------------------
Python, JavaScript, TypeScript, Java, C#, Kotlin, Dart, Bash, Rust, Go, C++, C, PHP, Ruby, PowerShell, SQL, R, Scala, MATLAB और COBOL/Assembly की स्वचालित पहचान:
- शीर्षक के नीचे `***`, अनुभाग के लिए `===` और उप-अनुभाग के लिए `---` लगाएँ।
- कोड ब्लॉक के लिए पंक्तियों से पहले **3 स्पेस** जोड़ें:

   def binary_search(arr, target):
       low, high = 0, len(arr) - 1
       while low <= high:
           mid = (low + high) // 2
           if arr[mid] == target:
               return mid
           elif arr[mid] < target:
               low = mid + 1
           else:
               high = mid - 1
       return -1
